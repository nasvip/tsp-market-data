# tsp-market-data

给 [Tick Stock Panel](https://github.com/shy3130/tick-stock-panel) 用的**一个数据源插件**，接管四个数据集：

**五档盘口 · 分钟K · 全量分钟 · 财务五表**

全部走公开行情/财报接口，**不需要任何 API Key、不消耗任何额度**。用来替代按积分计费的商业数据源。

## 特性

| 数据集 | 上游 | 覆盖范围 | 兜底 |
|---|---|---|---|
| `depth5` 五档盘口 | 腾讯 `qt.gtimg.cn` | 批量 400 只/次，含买五卖五与毫秒时间戳 | 新浪 `hq.sinajs.cn` |
| `minute` 分钟K | 新浪 1 分钟 | 单只 1900 根 ≈ **8 个交易日**，OHLC + 成交额 | — |
| `full_minute` 全量分钟 | 腾讯 `m1` K 线 | 当日全量，全市场一轮约 1.5 分钟 | 新浪当日分钟 |
| `financial` 财务五表 | 东方财富 F10 | 全市场 **12 个季度**，带公告日期 | — |

财务五表：`metrics` / `income` / `balance_sheet` / `cash_flow` / `shares`。
一般企业、银行、证券、保险四套报表模板自动回退，字段逐列对齐面板契约。

## 安装

1. 构建插件包：

   ```powershell
   pwsh ./build.ps1        # 产出 dist/market_data.zip
   ```

2. 面板 → **设置 → 导入与备份** → 选择 `market_data.zip`（不要解压）
3. 面板 → **设置 → 数据源** → 找到「行情与财务（东财+腾讯+新浪）」
4. 点「**选择启用能力**」，勾选要接管的数据集
5. 逐项点「试拉」验证

能力路由是**按数据集独立**的：可以只把五档和全量分钟切过来，日K/实时继续走 TickFlow 或 fuyao。

> 插件**更新**后需要 `docker restart` 主程序容器才生效；首次安装即时生效。
> 卸载前要先把引用它的能力切回别的源，否则面板会拒绝卸载。

## 数据口径

- 五档数量单位**手**，`timestamp` 为毫秒 Unix 时间戳
- 分钟类 `volume` 单位**手**，`amount` 单位**元**
- 财务的 `period_end` / `announce_date` 为 `YYYY-MM-DD`，`metrics` 百分比列为**百分点**（24.47 表示 24.47%）

## 已知限制

- **分钟历史约 8 个交易日**（新浪 `datalen` 上限实测 1970，插件取 1900 留余量）。做更长周期的分钟回测不够用。
- **全量分钟没有成交额**（腾讯 `m1` 接口不提供），该列留空，面板均价线会降级显示 `—`。
- 银行报表没有「流动资产合计 / 存货 / 短期借款」等科目，对应列为空，属行业口径差异。
- `metrics.roe_diluted` 上游无摊薄 ROE 单列，保持空值，不用加权 ROE 顶替。
- 首次财务全表同步约 10 分钟，建议收盘后跑；之后为增量。

## 风险提示

所有上游都是**非官方公开接口**，随时可能限流、改字段或失效。代码里有 4 req/s 限速、3 次重试、15 分钟缓存，但**不保证长期可用**。

如果需要生产级稳定性，请使用有正式授权的数据服务，而不是本项目。

## 开发

```powershell
python scripts/validate_manifest.py   # 清单校验（复刻面板规则，不联网）
python scripts/run_tests.py           # 单测（不联网，22 项）
python scripts/smoke.py               # 真实接口冒烟
pwsh ./build.ps1                      # 打包
```

依赖：Python 3.11+、宿主的 `polars`。HTTP 只用标准库，无第三方依赖。
